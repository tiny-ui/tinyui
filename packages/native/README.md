# tinyui-native

[TinyUI](https://github.com/tiny-ui/tinyui) 页面可用的宿主能力：`navigation`、`http`、`i18n`、`session`、`ui`（toast 与对话框）、`linking`、`clipboard`、`crypto`、`device`、`analytics`、`storage`、`store`、`events`，以及调宿主自定义能力的 `host.call`。Kotlin 侧由宿主建一个 `TinyUIHost` 提供。

API 见仓库 `docs/native-api.md`；与 `tinyui-core` 同版本号。
